# 06 设置页卡片与触发时机

Status: ready-for-agent
Type: task
Part of: `.scratch/sync-client/spec.md`
Blocked by: 05

## 目标

让开关、地址、令牌、状态与两个按钮在设置页可用，并把同步从首屏包与侧栏状态里隔离出去。

## 改动点

- 设置页「数据概览」旁加一张「跨设备同步」卡：开关、服务地址、令牌输入（打码、可清除）、
  最近一次同步的时间与结果（成功 / 失败原因 / 冲突几条）、「立即同步」与「重新对账」两个按钮，
  以及一行说明：**关闭时应用仍是零网络请求**。用既有的 `Card` / `CardHeader` / `CardBody` 与表单件。
- 开机一次：接在 `main.tsx` 的 `syncFolderBackup()` 旁边，**动态 import** 同步引擎
  （不该进首屏包 —— 首屏预算 300 KB，现在用掉 167.3 KB gzip）。
- **不做定时轮询**：只有开机一次 + 手动。
- 冲突提示：`lm:sync.conflicts` 在界面上给**一行**提示（可点，进设置卡明细：模块 + 条目标题 +
  服务端那份的时间），不弹模态、不阻塞。
- 侧栏底部那行保存状态**不改** —— 它只回答「本地写没写成功」。

## 验收

- 关闭开关时，整轮操作（含开机）零网络请求。
- 开启后开机自动同步一次；「立即同步」能手动触发。
- `npm run size` 显示首屏包体积不因同步代码上升（动态 import 生效）。
- 冲突的一行提示可点开明细。

## 测试

按既有页面测试的写法加几条（设置卡与那行提示）；不测 React 渲染细节以外的东西。

## 不做

手机端、TLS、端到端加密、定时轮询、字段级合并。
