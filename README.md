# Life Manager

> 一个纯本地的个人生活与工作管理应用。读书、开发、写作、健身、饮食、游戏，加上今日计划与统计。
> 没有账号、没有后端、没有网络请求 —— 数据只存在你自己的浏览器里，导出来就是一个 JSON 文件。

## 为什么是「纯本地」

个人数据（读了什么书、写了多少字、练了什么、吃了什么）不需要经过别人的服务器。所以这个项目：

- **没有后端**：`npm run preview` 出的静态文件丢到任何地方都能跑，断网也能用。
- **没有账号**：打开即用，没有登录、没有同步、没有遥测。
- **数据可带走**：一键导出 JSON，导入时还能选「合并」或「覆盖」。
- **不吞数据**：任何破坏性操作前都会自动留快照；「清除数据」也保留快照，随时能回滚。
  代码里没有 `localStorage.clear()`。

## 功能

| 模块       | 能做什么                                                                       |
| ---------- | ------------------------------------------------------------------------------ |
| 首页总览   | 可拖拽 / 可调宽度 / 可隐藏的仪表盘，快速捕获、今日聚焦、待办、备忘、活动热力图 |
| 今日计划   | 任务、子任务、重复规则、优先级、标签、看板视图                                 |
| 读书       | 书单、进度与页码换算、阅读流水、书摘笔记（宽屏是「列表 + 笔记」双栏）          |
| 开发工作   | 项目、里程碑、工作项、开发日志、工时流水                                       |
| 写作       | 稿件进度、目标字数、版本快照                                                   |
| 健身计划   | 训练计划、动作 / 组数 / 重量记录、训练流水与部位标签                           |
| 饮食计划   | 三餐记录、热量与三大营养素、饮水量、每日目标                                   |
| 游戏娱乐   | 游戏库、游玩流水、成就进度                                                     |
| 统计       | 活动热力图、趋势图与各模块进度                                                 |
| 数据与设置 | 导出 / 导入、自动备份回滚、外观与密度、快捷键表                                |

## 技术栈

React 18 + TypeScript（严格模式，禁用 `any`）+ Vite 6 + Tailwind CSS 3 + zustand（`persist`）+ react-router + zod + @dnd-kit。
依赖刻意保持克制：没有 UI 组件库、没有图表库、没有日期库的重度封装，图表与设计系统都是自己写的。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```

需要 Node 20 以上（CI 用 22）。

## 目录结构

```
src/
  components/
    layout/    应用外壳、侧栏、命令面板、双栏布局（MasterDetail）
    ui/        设计系统：按钮、输入、卡片、弹层、标签…
    charts/    自绘的图表（热力图、折线、柱状）
    dashboard/ 首页仪表盘栅格
  pages/       每个模块一个页面
  store/       zustand store，按模块拆分；persist / 归一化在 store 层统一处理
  services/    备份、导入导出、schema 校验
  utils/       日期、统计、搜索、标签、快捷语法解析…
  test/        vitest 启动配置与测试工具
docs/          设计文档与优化路线图
scripts/       构建产物体积预算等小工具
```

## 数据与隐私

- 所有数据存在浏览器的 `localStorage`，key 统一带 `lm:` 前缀，方便「只清本应用的数据」。
- **每日自动快照**：每天第一次打开应用时会留一份快照，最多保留 10 份，可在「数据与设置」里回滚。
- **导入 / 导出**：导出是完整 JSON（含外观设置）；导入前会校验并给出预览，再选合并或覆盖。
- **数据体积**：设置页会显示当前占用，接近浏览器约 5MB 的上限时给出告警。
- **升级不丢数据**：读出来的旧数据会逐条归一化到当前结构，缺字段补齐、坏记录丢弃而不是让页面崩掉。

## 质量门

| 命令                | 作用                                    |
| ------------------- | --------------------------------------- |
| `npm run typecheck` | TypeScript 全量类型检查（`tsc -b`）     |
| `npm run lint`      | ESLint（含 `jsx-a11y` 全量规则）        |
| `npm run test`      | vitest 单元与组件测试（600+ 条）        |
| `npm run build`     | 生产构建                                |
| `npm run size`      | 首屏 gzip 体积预算（≤ 300KB，构建后跑） |

CI（`.github/workflows/ci.yml`）按 `typecheck → lint → test → build → size` 顺序跑。

> `format:check` 暂时没有进门禁：仓库里有 57 个历史文件不符合 Prettier 格式，一次性 reformat
> 会淹没真正的改动。新写的文件请保持 `npx prettier --write <file>` 干净。

## 快捷键

| 按键           | 作用                                            |
| -------------- | ----------------------------------------------- |
| `Ctrl / ⌘ + K` | 打开命令面板（跳页面、切换外观）                |
| `/`            | 打开命令面板并直接搜索                          |
| `n`            | 新建当前模块的条目                              |
| `g` 后接 `1-9` | 跳转到对应主页面（1 首页、2 今日计划、3 读书…） |
| `Esc`          | 关闭弹层与抽屉                                  |

命令面板里可以直接录入：`写周报 !高 @明天 #工作`（`!` 优先级、`@` 日期、`#` 标签），
输入 `#工作` 则跨模块列出所有打了该标签的记录。
