# 工作生活专属 App 产品设计文档

## 1. 产品概述

### 1.1 产品定位
一款**个人专属的工作生活管理应用**，整合日常计划、学习、工作、健康、娱乐等核心场景，帮助用户在一个地方管理自己的生活。

### 1.2 目标用户
**仅个人使用**，不面向公众开放。

### 1.3 运行环境
- 在电脑浏览器中本地运行
- 数据保存在本地（localStorage）
- 无需登录、无需联网、无需云数据库
- 无需部署到服务器
- 不支持手机端

### 1.4 数据持久化
- 刷新、关闭、重新启动后数据不丢失
- 使用浏览器 localStorage 存储
- 支持手动导出/导入 JSON 备份

## 2. 功能模块

### 2.1 首页总览
**核心目标**：一眼看清今天要做的事，快速记录临时想法。

**功能清单**：
- 今日计划摘要（显示今天待完成的任务数量和关键任务）
- 快速备忘输入框（随手记下临时想法，回车即存）
- 各模块关键数据卡片（如在读 2 本书、进行中项目 3 个等）

### 2.2 今日计划
**核心目标**：管理今天的任务，追踪完成情况。

**功能清单**：
- 添加任务（标题、描述、优先级、截止日期）
- 编辑任务
- 删除任务
- 标记任务完成/未完成
- 按优先级排序（高/中/低）
- 按状态筛选（待办/已完成）

### 2.3 读书
**核心目标**：追踪阅读进度，积累读书笔记。

**功能清单**：
- 添加书籍（书名、作者、分类）
- 设置阅读状态（想读/在读/已读）
- 记录阅读进度（百分比或页数）
- 添加读书笔记
- 编辑/删除书籍

### 2.4 开发工作
**核心目标**：管理开发项目，追踪任务进度。

**功能清单**：
- 创建项目（项目名称、描述、状态）
- 为项目添加任务
- 任务状态流转（待办/进行中/已完成）
- 设置任务优先级
- 记录任务进度

### 2.5 写作
**核心目标**：管理写作项目，追踪创作进度。

**功能清单**：
- 创建写作项目（文章/文案/书籍等）
- 设置状态（草稿/进行中/已完成）
- 字数统计
- 记录创作笔记/想法
- 编辑/删除项目

### 2.6 健身计划
**核心目标**：制定训练计划，记录训练数据。

**功能清单**：
- 创建训练计划（如"胸肌日""腿部训练"）
- 记录每次训练（日期、训练内容）
- 记录具体动作（动作名称、组数、次数、重量）
- 查看历史训练记录

### 2.7 饮食计划
**核心目标**：记录饮食，追踪营养摄入。

**功能清单**：
- 记录每日饮食（早餐/午餐/晚餐/加餐）
- 食物分类（主食/蛋白质/蔬菜/水果等）
- 简单热量统计
- 查看历史饮食记录

### 2.8 游戏娱乐
**核心目标**：记录游戏进度，管理娱乐时间。

**功能清单**：
- 添加游戏（游戏名称、平台）
- 设置状态（在玩/已通关/搁置）
- 记录游戏时长
- 记录游戏进度/成就
- 编辑/删除游戏

### 2.9 数据与设置
**核心目标**：管理数据备份和应用配置。

**功能清单**：
- 导出所有数据为 JSON 文件
- 导入 JSON 数据文件
- 清除所有数据（二次确认）
- 主题切换（亮色/暗色）

## 3. 技术方案

### 3.1 技术栈
- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式方案**：Tailwind CSS（简洁现代风格）
- **数据存储**：浏览器 localStorage
- **路由**：React Router

### 3.2 项目结构
```
src/
├── components/       # 通用组件
├── pages/            # 各模块页面
├── hooks/            # 自定义 hooks
├── utils/            # 工具函数
├── types/            # TypeScript 类型定义
└── App.tsx           # 主入口
```

### 3.3 数据模型
每个模块独立定义数据结构，统一使用 localStorage 存储，支持 JSON 导出/导入。

## 4. 视觉设计

### 4.1 设计风格
**简洁现代风**，参考 Notion、Linear 的设计语言：
- 干净的留白
- 清晰的信息层级
- 克制的配色（主色 + 中性色）
- 简洁的图标
- 流畅的交互反馈

### 4.2 主题
- 亮色主题（默认）
- 暗色主题（可切换）

## 6. 开发原则

1. **每次改动必须提交 Git commit**，便于追踪和回滚
2. **每次改动后必须编写和更新测试**，交付前确保所有测试通过
3. **功能导向**：每个模块都要有符合自身场景的核心功能，不是千篇一律的任务列表
4. **数据优先**：确保数据持久化可靠，不丢失用户数据
5. **渐进式开发**：先完成 MVP，再逐步扩展功能
